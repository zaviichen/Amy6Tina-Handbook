一、SMA 与 EMA 的计算方式有何不同？
简单移动平均线（SMA）：最直观的一种均线。它就是过去 N 个周期的收盘价的简单算术平均值。公式：SMA = (P1 + P2 + … + PN) / N其中每个价格的权重完全相等。超过 N 个周期之前的数据会被直接“丢弃”。
指数移动平均线（EMA）：也叫指数加权移动平均线。它对近期价格赋予更高的权重，历史数据的影响会逐渐衰减，但不会被完全忽略。计算时会引入一个平滑因子（α = 2 / (N + 1)），EMA 值 = α × 当日价格 + (1 - α) × 前一日 EMA。这使得 EMA 对价格变化的反应更加灵敏。
核心区别：
SMA：一视同仁，所有历史数据权重相同，超过周期的数据直接丢弃。

EMA：近期数据权重更高，历史数据权重呈指数级衰减，但不会完全丢失。

二、在实战中的应用场景
趋势识别
金叉/死叉信号（交叉策略）
短期均线向上穿越长期均线 → 金叉（买入信号）。
短期均线向下穿越长期均线 → 死叉（卖出信号）。
EMA 组合（如 9 日与 21 日 EMA）产生的交叉信号更快，但假信号也可能更多；SMA 组合信号更“干净”，但滞后明显。
动态支撑与阻力
上升趋势中，EMA 或 SMA 经常充当动态支撑，价格回调至均线附近获得支撑后继续上涨。
下跌趋势中则充当动态阻力。
EMA 因为贴近价格，对支撑阻力的反应更及时，尤其在震荡或趋势加速阶段表现突出。

EMA 的缺点：
过于敏感，容易产生更多假信号（whipsaw），尤其在震荡市。

对老数据的权重虽衰减但仍有影响，有时会“拖泥带水”。
